# LocalVibes

**Every Product Deserves a Platform....**

LocalVibes is a simple student web project that helps local vendors showcase products and lets customers browse a local marketplace.

## Files
- `index.html` – website homepage
- `MarketPlace.html` – marketplace page
- `style.css` – page styling
- `script.js` – marketplace interactions

Open `index.html` in a browser to run the project. This is a front-end demo; data is stored in the browser using localStorage and it does not process real payments.
